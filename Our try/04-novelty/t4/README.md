# Задача T4: Mixture Density Network (MDN) для неєдиних рівноваг плазми

## Огляд
Дослідження режиму відмови стандартних нейромереж при наявності неєдиних розв'язків нелінійних диференціальних рівнянь (модель Братý / Гельфанда, ефект E4). Доведено, що L²-регресор (MSE) колапсує до нефізичного гілочного середнього з нев'язкою $g \approx 1.10$, тоді як Mixture Density Network (MDN) навчається мультимодального умовного розподілу, генеруючи фізично валідні розв'язки ($g = 0.012 \ll 0.10$) з рівномірним покриттям обох гілок (48.4% / 51.6%).

## Команда відтворення
```bash
"fusion equilibrium challenge/starter/.venv/bin/python" "Our try/04-novelty/t4/run_t4.py"
```

## Ключові результати
- **L² Regressor:** середня нев'язка $g = 1.0979$, частка валідних розв'язків ($g < 0.10$) = **2.8%**.
- **MDN (K=2):** середня нев'язка $g = 0.0121$, частка валідних розв'язків = **98.4%** (обидва моди валідні у 97.6% випадків).
- **Покриття гілок:** 48.4% нижня гілка / 51.6% верхня гілка (відсутність mode collapse).
- **Вердикт:** **ПІДТВЕРДЖЕНО (CONFIRMED)** за критеріями [THEORY.md](THEORY.md).
