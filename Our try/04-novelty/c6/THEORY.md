## 0. Твердження

**C6** (`00-decisions/CONJECTURES.md`): одночасні конформні смуги на полі 65×65 — **правильна форма**
UQ-члена. Спростує: емпіричне покриття виявиться **недосяжним без абсурдної ширини**.

**C4-Cal** (друга половина C4; половину GS_score спростовано → R12): додавання `Calibration`
**змінить упорядкування** бейзлайнів. Спростує: упорядкування збігається з тим, що дає `S`.

Обидві перевірки використовують ті самі смуги, тому йдуть разом.

## 1. Дані

- **Навчання** — потокові розряди 0–35, **валідація** 36–39, **тест** 60–67: розбиття C2/C4
  (`c2_cache`). У тесті 8 розрядів, 1 521 кадр.
- **Калібрування** — 24 розряди DIII-D з `c1/hf_shots.json` без індексу 0. Індекс 0 — це потоковий
  розряд №0 з навчання; перевірено за першим кадром ψ, решта 24 не збігаються з жодним розрядом
  навчання, валідації чи тесту. Усього 5 580 кадрів (`c6/fetch_cal.py` → `c6_cal_cache`). Ознаки
  й кадри обробляються **так само, як тест** (`c2.train.test_inputs`: усі кадри, NaN → 0).
- **Поділ калібрування за розрядами:** перестановка `numpy.random.default_rng(0).permutation(24)`,
  перші 12 розрядів — половина **A** (масштаб s(x)), решта 12 — половина **B** (квантиль).
  Форма P використовує всі 24.

## 2. Моделі

Ті самі 8, що в C4, **перенавчені** тим самим кодом і гіперпараметрами (`c4/train.py`, `c2/train.py`):
Linear Regression, Ridge (CV), Random Forest, MLP (sklearn), Simple MLP, Conv Decoder (3 зерна),
UNet_Lite (пласка вага, 3 зерна), PCA+Ridge (`SCORE.md`). Кожна навчена модель дає прогноз
**і для калібрування, і для тесту**: смуга мусить калібруватися на тій самій моделі, тож прогнози
C4 повторно не використовуються.
**Нульова модель N0** — середнє поле ψ по кадрах навчання (стала карта), еталон ширини.
**Контроль відтворення (не критерій):** S і R²ψ на тесті порівнюються з `c4/eval.json`. Для мереж
на MPS очікуються невеликі розбіжності.
**«Точні» моделі для C6** зафіксовано за C4 (R²ψ ≥ 0,9): MLP (sklearn), Simple MLP, Conv Decoder,
UNet_Lite. Список фіксовано за назвою, незалежно від відтвореного R²ψ.

## 3. Форми смуг

Залишок r_t(x) = ψ_true,t(x) − ψ̂_t(x), x — уся сітка 65×65 (4 225 пікселів, та сама область, що й у R²ψ).
Рівні a ∈ A = {0,50; 0,80; 0,90; 0,95}; **головний рівень — 0,90**. Квантиль спліт-конформного методу:
k = ⌈(n+1)·a⌉-те найменше з n калібрувальних значень.

- **M (головна, одночасна, студентизований максимум).** s(x) — стандартне відхилення r_t(x) по
  кадрах половини A (знизу обмежене 10⁻⁶ · медіана s). Оцінка кадру e_t = max_x |r_t(x)| / s(x).
  Q_a — конформний квантиль e по кадрах половини B. Смуга: ψ̂ ± Q_a·s(x).
- **P (довідкова, поточкова).** q_a(x) — конформний квантиль |r_t(x)| по всіх 24 калібрувальних
  розрядах окремо для кожного пікселя. Смуга: ψ̂ ± q_a(x).
- **Бонферроні** потребує n ≥ 4 225/(1 − a) − 1 калібрувальних кадрів, тобто 8 449 при a = 0,5.
  Маємо 5 580, тож ширина нескінченна на всіх рівнях A. Це лише арифметика, прогону немає.

## 4. Що міряється на тесті

- **Спільне покриття** emp_J(a) — частка тестових кадрів, де |r_t(x)| ≤ півширина(x) **в усіх** x.
  Для P додатково — поточкове покриття (середнє по кадрах і пікселях).
- **Ширина** W(a) — середня по x півширина.
- **Потрібне розширення** c*(a) — найменше c ≥ 1, за якого смуга ψ̂ ± c·півширина має emp_J ≥ a
  на тесті. Це оракул тестової вибірки: яка ширина *насправді* потрібна на нових розрядах.
  Для M: c* = max(1, e_(⌈a·n_test⌉) / Q_a). W*(a) = c*(a)·W(a).
- **Відносна ширина** κ*(a) = W*_model(a) / W*_N0(a), де N0 обробляється **так само** (форма M, своє
  s(x), своє c*). Без розширення — κ(a) = W_model(a) / W_N0(a).
- **Невизначеність:** 1000 бутстреп-повторень (rng 0) **одночасно** по тестових розрядах і по
  розрядах половини B (Q_a перераховується; s(x) фіксоване). Довірчі інтервали — 95 % перцентильні.
  Для мереж кожна величина спершу усереднюється по 3 зернах.

## 5. Критерії C6 (головний рівень a = 0,90; чотири «точні» моделі з §2)

- **C6 ПІДТВЕРДЖЕНО** — для **всіх чотирьох** точкова оцінка emp_J,M(0,90) ≥ 0,85 **і** κ*(0,90) ≤ 0,5.
- **C6 СПРОСТОВАНО** — для **≥ 2 із чотирьох** κ*(0,90) ≥ 1,0. Тобто щоб справді досягти 90 %
  спільного покриття на нових розрядах, потрібна смуга не вужча за кліматологічну смугу N0
  («абсурдна ширина»).
- **УТОЧНЕНО** — в інших випадках. Тоді назвати, що саме не пройшло (недопокриття чи ширина)
  і для яких моделей.
- **Звітуємо додатково (не критерій):** усі рівні; спільне покриття форми P (очікується значно
  нижче номіналу, і саме тому потрібна одночасність); ціна одночасності W_M/W_P; область
  `mask_coarse` (2 444 пікселі); лінійні моделі; розкид покриття по тестових розрядах.

## 6. Член Calibration і критерій C4-Cal

Смуги — форма M з §3 для кожного прогону (модель × зерно).
- **Cov** (формула `metric-design.md`, emp = emp_J,M на тестових кадрах повтору):
  Cov = 1 − (1/4)·Σ_a |emp(a) − a| / max(a, 1 − a).
- **Sharp** = (1/4)·Σ_a clip(1 − W_a / W_N0,a, 0, 1). Ширини — як подано, **без** оракульного
  розширення. W_N0,a — смуга N0 з тих самих калібрувальних даних.
- **Calibration (головний варіант) = Cov × Sharp.** Підстава: `metric-design.md` вимагає гостроту
  («Захист від геймінгу — обов'язковий»), і першим варіантом там названо «множення на нормовану
  ширину». Лише покриття з конформними смугами дає ≈ однакове значення для всіх моделей за
  побудовою. Тому такий варіант звітуємо, але критерієм не робимо.
- **S′_Cal(w_u)** = (1 − w_u)·[ваги metric-design без GS і Calibration, 0,40 : 0,10 : 0,10 : 0,15,
  нормовані на 1] + w_u·Calibration. **Головне w_u = 0,10/0,85 = 0,1176.**
  Скан: w_u ∈ {0; 0,05; 0,10; 0,1176; 0,15; 0,20; 0,25; 0,30}.
  Члени S рахуються функціями офіційного скорера, як у `c4/evaluate.py`.
- **Невизначеність:** 1000× бутстреп по тестових розрядах (rng 0, як у C4). Калібрування фіксоване.
  Мережі усереднюються по 3 зернах усередині кожного повтору.
- **Стійка перестановка пари (i, j):** у ≥ 95 % повторень S ставить i вище j, а S′_Cal — j вище i,
  в одному й тому самому повторі.
- **C4-Cal ПІДТВЕРДЖЕНО** — при головному w_u є ≥ 1 стійка перестановка.
- **C4-Cal СПРОСТОВАНО** — при головному w_u немає жодної перестановки навіть у точковому порядку
  (τ = 1), або є лише нестійкі (< 95 %).
- **Звітуємо додатково (не критерій):** Calibration лише з покриття; **повна S′** з обома новими
  членами за вагами metric-design (0,40 / 0,10 / 0,10 / 0,15 / 0,15 / 0,10). У ній GS_score — за
  означенням C4 (`c4/THEORY.md`, g_ref з `c4/gref.json`), перерахований на нових прогнозах. Це
  повне початкове формулювання C4. Також: поріг w_u першої стійкої перестановки; кореляція
  Спірмена Calibration з R²ψ і з Consistency по моделях.

## 7. Що НЕ перевіряється

Адаптивні (залежні від входу) смуги; смуги в базисі PCA; конформізація похідних скалярів замість
пікселів; власна UQ моделей (ансамблі зерен, розкид дерев). Висновок C6 стосується **форми M** проти
P і Бонферроні, а не всіх можливих одночасних смуг.
