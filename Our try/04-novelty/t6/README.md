# Задача T6: HénonNet для оберненої задачі спектру магнітних збурень (D3 / c5)

## Огляд
Дослідження оберненої задачі відновлення параметрів спектру збурень $(m, n)$ (амплітуди $a$ та фази $\phi$) за фазово-роздільною екскурсією токомапу на фоні склоподібного рельєфу (glassy landscape, E40). Порівнюється нелінійний МНК (NLS TRF з чисельним якобіаном), глобальна оптимізація через диференціальну еволюцію (Differential Evolution, DE) та симплектична інверсна мережа HénonNet.

## Команда відтворення


## Ключові результати
1. **Фаза 1 (Single-mode $m=2$, тест на мітигацію ризику):**
   - NLS: успіх **35.0%** (застрягання у локальних мінімумах фази);
   - DE: успіх **100.0%**;
   - HénonNet: успіх **95.0%** (середня похибка амплітуди 0.9%, фази 8.8°, час 0.20 мс).
2. **Фаза 2 (Dual-mode $2/1 + 3/1$, головний тест):**
   - NLS: успіх **0.0%** (середня похибка фази $96.9^\circ$, повний колапс, що підтверджує R13);
   - DE: успіх **100.0%** (висока точність, проте вимагає 4.9 с на екземпляр);
   - HénonNet: успіх **65.0%** (похибка амплітуди 5.9%, фази 5.4°, інференс **0.21 мс**, прискорення $\times \mathbf{23\,635}$ відносно DE).
3. **Вердикт:** **СПРОСТОВАНО (REFUTED)** за суворим критерієм предреєстрації $s \ge 70\%$ ($s = 65\% < 70\%$). HénonNet кардинально перевершує NLS (65% проти 0%), але на складних багатомодових конфігураціях класична глобальна оптимізація (DE) залишається надійнішою за точністю ціною величезного обчислювального часу.
