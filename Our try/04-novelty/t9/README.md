## Що робить скрипт `run_t9.py`

1. **Оцінка кривини:** Знаходить O-точку як екстремум $\psi(R, Z)$ (де $\nabla \psi = 0$), обчислює матрицю Гессе $H$ та характеристичну кривину $\lambda_{\mathrm{axis}} = \sqrt{|\det H|}$.
2. **Розподіли:** Будує гістограми та квантилі $\lambda_{\mathrm{axis}}$ для популяцій DIII-D ($N=280$) та MAST ($N=60$), генерує рисунок `t9_lambda_distribution.png`.
3. **Терцилі:** Розбиває тестову вибірку C2-split (8 розрядів, 1521 валідний кадр) на 3 терцилі за $1/\sqrt{\lambda_{\mathrm{axis}}}$ ($T_1$: гостра вісь, $T_2$: середня, $T_3$: пласка вісь).
4. **Бейзлайни:** Оцінює `PCA+Ridge` та `UNet_Lite` у кожному терцилі.
5. **Кластерний бутстреп:** Рахує 95% довірчі інтервали шляхом ресемплінгу по **розрядах (shots)** ($B=1000$), а не по окремих кадрах.
6. **Вердикт:** Звіряє результати із зареєстрованими критеріями фальсифікації та зберігає метрики у `results.json` і графік у `t9_strata_results.png`.

## Вердикт за критеріями THEORY.md

**СПРОСТОВАНО (REFUTED)**:
- Довірчі інтервали між стратою $T_1$ та $T_3$ повністю перекриваються для обох моделей:
  - PCA+Ridge: $T_1 = [3.61; 5.92]$, $T_3 = [2.91; 7.66]$ (похибка в $T_3$ не перевищує $T_1$ у $\ge 1.3\times$).
  - UNet_Lite: $T_1 = [6.18; 8.83]$, $T_3 = [6.21; 13.08]$ (перекриття істотне).
- Кореляція Спірмена між $1/\sqrt{\lambda}$ та похибкою положення осі незначна ($|\rho| < 0.15$):
  - PCA+Ridge: $\rho = -0.033$
  - UNet_Lite: $\rho = +0.068$
- Жоден із двох зареєстрованих критеріїв підтвердження не спрацював. Локальна кривина O-точки $\lambda_{\mathrm{axis}}$ не є домінуючим фактором похибки відновлення положення осі.
