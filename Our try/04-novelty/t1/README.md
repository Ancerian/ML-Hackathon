# T1 (R12, E38): Шлюз та штраф Град-Шафранова для переупорядкування бейзлайнів

Ця тека містить артефакти виконання задачі **T1** згідно з `roadmap.md` та зареєстрованої перед початком експерименту гіпотези у [`THEORY.md`](../../../Our%20try/04-novelty/t1/THEORY.md).

## Контекст задачі
- **E38:** Моделі прямого виходу карти (як-от UNet_Lite) мають високий формальний скор $S \approx 0.65$, але нефізичну нев'язку рівноваги $g(\psi) \approx 0.86$, що суттєво гірше за істину з 1% шуму ($g_{\mathrm{ref}} \approx 0.634$).
- **R12:** Адитивне додавання члена GS до $S$ не переупорядковувало моделі надійно (лише 74–75% у бутстрепі), оскільки адитивна вага не могла подолати розрив між лінійними моделями та мережами.
- **T1:** Перевірка, чи нелінійний шлюз $S \cdot \mathbf{1}[g < g_{\mathrm{ref}}]$, сигмоїда чи штраф log $g$ забезпечують **надійне ( $\ge 95\%$ у бутстрепі)** переупорядкування.

## Реалізація API (`gs_gate.py`)

Модуль надає функцію:
```python
def gate(psi, score, g_ref=0.634088, mode='hard', k=10.0, beta=1.0) -> float
```
- `mode='hard'`: $S'_A = S \cdot \mathbf{1}[g < g_{\mathrm{ref}}]$
- `mode='sigmoid'`: $S'_B = S / (1 + \exp(k \cdot (g - g_{\mathrm{ref}})/g_{\mathrm{ref}}))$
- `mode='log'`: $S'_C = S \cdot \exp(-\beta \cdot \max(0, g - g_{\mathrm{ref}})/g_{\mathrm{ref}})$

- **Оригінальний $S$:** UNet_Lite > MLP (sklearn) > PCA+Ridge > Linear Regression

- **Sigmoid Gate $S'_B$:** MLP (sklearn) > PCA+Ridge > Linear Regression > UNet_Lite ($\tau = 0.000$)
