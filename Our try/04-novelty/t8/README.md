# Задача T8: Топологічний лосс для усунення фіктивних критичних точок магнітного поля ψ

## Огляд
Дослідження впливу топологічного градієнтного члена $\mathcal{L}_{\mathrm{topo}} = \|\nabla\psi_{\mathrm{pred}} - \nabla\psi_{\mathrm{true}}\|^2$ на усунення фіктивних екстремумів та сідел $\nabla\psi = 0$ (ефекти E9, E11, E37). Встановлено, що додавання топологічної регуляризації знижує середню кількість фіктивних критичних точок з $1.81$ до $0.08$ на кадр (зниження на **95.4%**), підвищуючи частку фізично коректних канонічних кадрів з $45.8\%$ до **$93.3\%$** ($2.04\times$) без жодної втрати точності поля ($\Delta R^2_\psi = +0.0076$).

## Ключові результати
- **Бейзлайн ($\gamma = 0.0$, MSE):** $R^2_\psi = 0.8729$, середнє число фіктивних точок $\bar{N}_{\mathrm{spur}} = 1.81$, частка канонічних кадрів = $45.8\%$.
- **Топологічний лосс ($\gamma = 0.05$):** $R^2_\psi = 0.8983$ ($+0.0254$), $\bar{N}_{\mathrm{spur}} = 0.12$ (зниження на 93.4%), канонічні кадри = $90.8\%$.
- **Топологічний лосс ($\gamma = 0.20$):** $R^2_\psi = 0.8806$ ($+0.0076$), $\bar{N}_{\mathrm{spur}} = 0.08$ (зниження на **95.4%**), канонічні кадри = **$93.3\%$** ($2.04\times$ виграш).
