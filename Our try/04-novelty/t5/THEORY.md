# ПРЕДРЕЄСТРАЦІЯ: Задача T5 (C6) — Одночасні конформні смуги для 2D поля ψ із частотною гарантією спільного покриття

**Дата:** 2026-10-09  
**Статус:** ЗАФІКСОВАНО ДО ЕКСПЕРИМЕНТУ  
**Гіпотеза C6 / T5:**  
Одночасні конформні смуги на основі максимального студентизованого залишку:
$$e_t = \max_{(i, j) \in \Omega} \frac{|r_t(R_i, Z_j)|}{\sigma(R_i, Z_j)}$$
забезпечують частотну гарантію сумісного покриття поля $\psi$ на сітці $65 \times 65$ (4 225 пікселів) на номінальному рівні $1 - \alpha = 0.90$ без роздування ширини смуги до абсурдних значень ($\kappa^* < 1.0$), на відміну від точкових смуг (які колапсують через множинне тестування) та поправки Бонферроні (яка дає $\infty$ на скінченних вибірках).

---

## 1. Параметри предреєстрації

1. **Неконформна статистика (Non-conformity score):**
   $$e_t = \max_{x \in \Omega} \frac{|\psi_{\mathrm{true}, t}(x) - \hat{\psi}_t(x)|}{s(x)}$$
   де $s(x) = \mathrm{std}(r_A(x))$ — поточкова оцінка шкали похибки по калібрувальній половині розрядів A (з нижнім порогом $10^{-6} \cdot \mathrm{median}(s)$).

2. **Одиниця обмінюваності (Exchangeability unit):**
   **Розряд (shot / discharge)**. Калібрувальні розряди (DIII-D cal 01–24) та тестові розряди (DIII-D stream 60–67) є взаємно незалежними фізичними імпульсами токамака.
   Бутстреп виконується кластерно по розрядах (1 000 повторень із поверненням по 8 тестових розрядах).

3. **Номінальний рівень:** $1 - \alpha = 0.90$ (головний). Додаткові рівні: $0.50, 0.80, 0.95$.

4. **Порівняльні бейзлайни невизначеності:**
   - **(i) Поточкова смуга (Pointwise, P):** Квантиль $q_{0.90}(x)$ рахується для кожного пікселя окремо. Спільне покриття колапсує до $\sim 0.01 - 0.06$.
   - **(ii) Поправка Бонферроні (Bonferroni):** Поріг $\alpha' = \alpha / 4225$. Для $N_{\mathrm{cal}} = 2869$ (або 5580) кадрів ранг квантиля $k = \lceil (N+1)(1 - \alpha') \rceil > N$, що дає нескінченну ширину ($W = \infty$).
   - **(iii) Нульова кліматологічна модель (Null N0):** Постійна карта середнього поля $\psi$ з навчання; еталон абсолютної ширини $W_{N0}$.

5. **Критерій успіху гіпотези C6:**
   - Емпіричне спільне покриття точних моделей (UNet_Lite, Conv Decoder, Simple MLP) на тесті лежить у діапазоні $[0.88, 0.92]$ або його 95% бутстреп-CI перетинає цей інтервал;
   - Відносна ширина смуги $\kappa = W / W_{N0} \le 0.50$ (смуга компактна і вужча за 50% кліматологічного розкиду).

6. **Критерій спростування (Falsification condition):**
   Гіпотеза **СПРОСТОВУЄТЬСЯ**, якщо:
   - Спільне покриття $\ge 0.88$ виявляється недосяжним без абсурдної ширини ($\kappa^* \ge 1.0$, тобто смуга ширша за кліматологічну модель N0);
   - АБО на рівні розрядів спостерігається систематичний збій, через який спільне покриття падає нижче $0.70$ для більшості моделей без перекриття номіналу.

7. **Стрес-тест навантаження (Distribution shift / OOD):**
   Перенесення смуги, каліброваної на DIII-D, на інший токомак — **MAST** (сферична геометрія, протилежний знак потоку, $R \in [0.06, 2.0]$ замість $[0.84, 2.54]$).
   Очікується: повне руйнування обмінюваності (exchangeability collapse) і деградація покриття до $0.00\%$.
