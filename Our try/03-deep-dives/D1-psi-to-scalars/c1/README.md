# C1 — перевірка «три кластери α ↔ три механізми» (2026-09-30)

**Вердикт: C1 спростовано → R10.** Встановлено механізм для положення осі → E36. E14 відтворено.
Повний розбір — у `../findings.md`, розділ «Перевірка C1». Передбачення й критерії зафіксовано
до запуску, у [THEORY.md](THEORY.md).

## Файли

| Файл | Що робить |
|---|---|
| `THEORY.md` | Механізми P1–P7 скорера, передбачення α, конкурентна гіпотеза H-alt, критерії вердикту. **Попередня реєстрація, після запуску не редагується** |
| `sweep_core.py` | Спільне ядро розгортки: ті самі збурення й нормування, що в `../conditioning.py` (імпортує його); розширена ε-сітка (12 точок); знак ψ закріплено (урок R9); сирі похибки для бутстрепу; паралельно |
| `alpha_tools.py` | Медіанні криві, локальні нахили, α глобальний (як у D1) і режимний (до насичення), точна одновимірна k-means + силует, бутстреп по розрядах |
| `step1_baseline.py` | Крок 1: 60 кадрів D1, три сімейства; відтворює α D1 до 4 знаків |
| `local_models.py` | Крок 2: параболоїд (P1, E14, R6) і «крапля» з X-точкою через увесь скорер |
| `e14_curvature.py` | Відтворюваний тест E14 / R6 (частина A `local_models.py`) |
| `cf_xpoint.py` | Крок 3: 12 однонульових рівноваг Серфона–Фрайдберга (7 парних + 5 непарних однорідних функцій, 12 умов), перевірка, розгортка, бутстреп по формах |
| `fetch_hf.py`, `hf_shots.json` | 25 розрядів `diii_d_train`, рівномірно за відсортованим списком HF (CC BY 4.0, Sophelio / General Atomics) |
| `real_sweep.py` | Крок 4: 28 розрядів DIII-D (280 кадрів), 3 демо (контроль), 3 MAST; бутстреп 1000×; шари за λ на осі |
| `summarise.py` | Крок 5: `results_c1.json`, `c1_alpha_samples.png`, `c1_m1_crossover.png` |
| `*.json`, `*.npz` | Результати (npz — сирі похибки, можна переаналізувати без перерахунку) |

## Відтворення (~6 хв на 8 ядрах)

```bash
cd "fusion equilibrium challenge/starter"
P="../../Our try/03-deep-dives/D1-psi-to-scalars/c1"
.venv/bin/python "$P/fetch_hf.py" --n 25          # один раз, ~0,36 ГБ
.venv/bin/python "$P/step1_baseline.py"            # ~15 с
.venv/bin/python "$P/local_models.py"              # ~30 с
.venv/bin/python "$P/cf_xpoint.py"                 # ~20 с
.venv/bin/python "$P/real_sweep.py" 1000           # ~2 хв
.venv/bin/python "$P/summarise.py"
```
