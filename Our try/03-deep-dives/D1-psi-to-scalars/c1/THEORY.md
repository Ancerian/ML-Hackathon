## 0. Що перевіряємо

**C1** (`Our try/00-decisions/CONJECTURES.md`). Три кластери α з E2 відповідають трьом механізмам:

| Кластер | α (D1) | Скаляри | Механізм за C1 |
|---|---|---|---|
| K1 | 0,535 / 0,547 | `R_axis`, `Z_axis` | положення екстремуму (O-точка) |
| K2 | 0,417 / 0,347 / 0,420 | `kappa`, `tri_top`, `tri_bot` | контур крізь сідло |
| K3 | 0,695 / 0,696 | `volume`, `li` | інтеграл |

Тут α — нахил log(медіана |Δf|/σ_f) проти log ε. Його отримано однією прямою через
ε ∈ {0,003 … 0,3} для білого шуму, на 60 кадрах трьох розрядів DIII-D.

## 1. Як скорер рахує скаляри (`fusion_scoring/`, v3.1)

- **Вісь.** Найсильніший внутрішній локальний максимум φ = s·ψ на вузлах сітки, плюс незалежне
  параболічне 3-точкове уточнення по R і по Z, обрізане до ±1 кроку (`o_point.py`).
- **LCFS.** Найнижчий рівень φ, на якому контур marching squares ще замкнений, охоплює вузол осі
  і повністю лежить у масці оболонки. Рівень шукається бісекцією, 22 кроки (`lcfs.py`).
  Рівень задає або сідло (X-точка), або дотик до маски.
- **Форма.** `kappa = (Zmax − Zmin)/(Rmax − Rmin)` — **значення** екстремумів контуру.
  `tri_top` / `tri_bot` = (R_geo − R(argmax Z)) / a та (R_geo − R(argmin Z)) / a — тобто
  **R-положення** найвищої й найнижчої точок. Однонульова плазма має найнижчу точку в X-точці
  або біля неї (`derive._shape_from_contour`).
- **`volume`** — перший момент багатокутника LCFS: інтеграл по області.
- **`li`** — ⟨B_p²⟩_V / (∮B_p dl / l_p)², де B_p = |∇ψ|/R через `np.gradient`, інтеграл
  по вузлах усередині LCFS.

Сітка DIII-D: ΔR = 0,0266 м, ΔZ = 0,050 м. σ(`R_axis`) = 0,0089 м ≈ ⅓ ΔR;
σ(`Z_axis`) = 0,0121 м ≈ ¼ ΔZ. Отже, «1σ» у D1 — це субпіксельний масштаб.

## 2. Механізми та передбачення α

Позначення: η — амплітуда збурення у вузлі (∝ ε); λ — кривизна (власне значення гесіана) у
відповідній критичній точці; h — крок сітки.

**P1. Положення гладкого екстремуму.**
- Гладке збурення (градієнт g, масштаб ≫ h) зсуває максимум на Δr = g/λ.
  **α = 1** за будь-якого ε, поки зсув малий порівняно з розміром області.
- Шорсткий шум (незалежний у вузлах) дає три режими:
  - (i) η ≪ λh²/2: дискретний максимум лишається у своєму вузлі, параболічне уточнення зсуває
    оцінку лінійно (δ = (n₊ − n₋)/(2·кривизна)) → **α = 1**;
  - (ii) η ≳ λh²/2: максимум стрибає в будь-який вузол, де спад ½λr² < η →
    Δr ~ √(2η/λ) → **α = ½**, **Δr ∝ 1/√λ**;
  - (iii) Δr досягає розміру області → насичення, α → 0.
- **Прогноз:** локальний нахил α(ε) для шорсткого шуму переходить 1 → ½ біля
  η* ≈ λh²/2. Глобальна пряма через обидва режими дає 0,5 < α < 1, і результат залежить
  від λ і діапазону ε. Це узгоджується з R6: 0,687 при λ = 1 і 0,841 при λ = 4.

**P2. Положення точки контуру, де дотична горизонтальна** (`tri_top`; і `tri_bot`, якщо
найнижча точка не в X-точці). На верхівці функція Z(s) уздовж контуру має екстремум, тож
**той самий механізм, що й P1**: для шорсткого шуму α = ½ у режимі стрибків, для гладкого α = 1.

**P3. Положення X-точки** (`tri_bot` однонульової плазми). Критична точка типу сідла:
гладке збурення → α = 1; шорсткий шум → стрибки, α ≈ ½, **той самий P1-механізм**, але з
|λ| сідла.

**P4. Значення екстремумів контуру** (`kappa`: Zmax, Zmin, Rmax, Rmin). Нормальний зсув
контуру δn = δφ_b/|∇ψ| + η/|∇ψ| лінійний за η. Значення максимуму гладкої функції під
збуренням змінюється в першому порядку на η, а не на √η. **α = 1** (екстремальна статистика
шуму вздовж контуру дає лише логарифмічний множник). Виняток — Zmin у X-точці: там відстань
рівня від сідла ~ √(δφ/λ) → **α = ½** для цієї компоненти.

**P5. Рівень LCFS.** Мінімакс по шляху через сідло: δφ_b ~ η·(множник порядку √log N) —
лінійно. Тож усі контурні величини успадковують P4, крім околу X-точки. Якщо ж рівень задає
дотик до маски, це теж лінійно.

**P6. `volume`.** δV ≈ ∮ δφ_b/|∇ψ| · 2πR dl. Біля X-точки |∇ψ| → 0, інтеграл розбіжний
логарифмічно: δV ~ η·log(1/η) → **α_eff ≈ 0,8–0,95** у досяжному діапазоні.

**P7. `li`.** δ∫|∇ψ|² = 2∫∇ψ·∇δψ (лінійний, знакозмінний) + ∫|∇δψ|² (додатний, ∝ η²k²;
для білого шуму k ~ 1/h, тобто великий). Плюс зміна області інтегрування (P6).
- Гладке збурення → **α = 1**.
- Білий шум → α від 1 до 2 з ростом ε (квадратичний член), тобто **α ≥ 1**, якщо область
  стабільна.
- Значення α < 1 для `li` може дати лише нестабільність LCFS (P5/P6) або насичення.

## 3. Дві конкурентні гіпотези (зареєстровано обидві)

| Скаляр | **C1** (механізм → кластер) | **H-alt** «положення проти значення» (для білого шуму, режим ii) |
|---|---|---|
| `R_axis`, `Z_axis` | K1: екстремум | ½ (P1) |
| `tri_top` | K2: сідло | ½ (P2) |
| `tri_bot` | K2: сідло | ½ (P3 / P2) |
| `kappa` | K2: сідло | ≈ 1, з домішкою ½ від Zmin у X-точці (P4) |
| `volume` | K3: інтеграл | 0,8–0,95 (P6) |
| `li` | K3: інтеграл | ≥ 1 (P7) |

**H-alt** передбачає **два** кластери, «положення» {`R_axis`, `Z_axis`, `tri_top`, `tri_bot`}
≈ ½ і «значення/інтеграли» {`kappa`, `volume`, `li`} ≳ 0,8, а також перехід α → 1 для гладкого
збурення **для всіх** скалярів. Старі числа D1 H-alt пояснює не повністю (`kappa` 0,42,
`tri_top` 0,35 < ½, `li` 0,70 < 1). Саме тому потрібні локальні нахили й синтетика.

## 4. Операційні означення

- **Локальний нахил** α(ε_j) = Δlog(медіана)/Δlog ε між сусідніми точками розгортки.
  ε-сітку розширено донизу: 12 точок, логарифмічно від 1·10⁻⁴ до 0,3.
- **Глобальний α** — пряма через ε ∈ [0,003; 0,3], як у D1. Потрібен для відтворення.
- **Режимний α** — пряма лише по точках, де медіанна похибка < 0,25 від розмаху
  скаляра по вибірці. Це «до насичення», σ-незалежно.
- **Кластеризація** — одновимірна k-means на 7 значеннях α для k = 2, 3, 4 із силуетом.
  Вважаємо, що «кластери є», якщо силует найкращого k > 0,5. **Належність** — розбиття
  7 скалярів на групи.
- **Стабільність** — бутстреп по розрядах (1000 повторень). Частка повторень, у яких розбиття
  збігається з еталонним.

## 5. Критерії вердикту (зафіксовано до запуску)

**C1 ПІДТВЕРДЖЕНО** — виконано всі три умови:
- (a) Локальні моделі відтворюють передбачення P1–P7 (±0,1), зокрема перехід 1 → ½ для P1 за λ.
- (b) Повна синтетика (Серфон–Фрайдберг з X-точкою через скорер) дає **розбиття C1**:
  {R_axis, Z_axis} {kappa, tri_top, tri_bot} {volume, li}. Силует > 0,5 при k = 3.
- (c) На реальних DIII-D (≥ 25 розрядів) розбиття C1 стабільне у ≥ 90 % бутстреп-повторень.
  MAST (3 розряди, `axis_sign`) дає те саме розбиття.

**C1 СПРОСТОВАНО** — будь-що з переліченого:
- (b) або (c) дають інше розбиття чи силует < 0,5;
- розбиття C1 стабільне менш ніж у 50 % повторень;
- довірчі інтервали α різних кластерів C1 перекриваються.

**C1 УТОЧНЕНО** — кластери стабільні (≥ 90 %), але (a) показує, що механізм інший.
Наприклад, K1 і K2 — один механізм (стрибки дискретного екстремуму), а відмінність між ними
кількісна. Тоді: R10 — для формулювання «три механізми», E36 — для точного формулювання
(механізм, режим шуму, межі за λ і ε).

**H-alt** оцінюється за тими самими (a)–(c) з власним розбиттям. Вона може бути підтверджена
незалежно від C1.

Проміжні випадки (наприклад, 50–90 % стабільності) записуємо як **«не вирішено»** із
числами. Вердикт не підганяємо.
