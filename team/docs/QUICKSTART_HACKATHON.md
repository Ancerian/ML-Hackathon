## 1. Системні вимоги та налаштування середовища (≤ 5 хв)

Вам потрібен **Python 3.12** (рекомендовано менеджер [`uv`](https://docs.astral.sh/uv/) або `python3.12-venv`):

```bash
# Крок 1. Перейдіть до стартового пакета змагання
cd "fusion equilibrium challenge/starter"

# Крок 2. Створіть віртуальне середовище Python 3.12 (через uv або venv)
uv venv --python 3.12 .venv
# або: python3.12 -m venv .venv

# Крок 3. Встановіть залежності (NumPy, PyTorch, Scikit-learn, Scikit-image, Datasets)
source .venv/bin/activate
pip install -r requirements.txt -r requirements-pytorch.txt
```

## 2. Перші 3 команди для перевірки працездатності (≤ 3 хв)

Після активації `.venv` запустіть послідовно:

```bash
# 1. Самоперевірка скорера: обов'язково має вивести COMPOSITE S = 1.0000
python local_score.py --mode perfect --n-shots 2

# 2. Нульова перевірка: скорер на нулях має показати S = 0.0000
python local_score.py --mode zeros --n-shots 2

# 3. Швидке завантаження 3 демо-розрядів для перевірки мережі (Hugging Face streaming)
python "../../Our try/03-deep-dives/D1-psi-to-scalars/c1/fetch_hf.py" --n 3
```

> **Важливо:** Якщо скорер на першій команді не повертає рівно `1.0000`, зупиніться і перевірте версії бібліотек (`scikit-image`, `scipy`). Дані розрядів у Git **не комітяться** — вони підтягуються локально в кеш.

## 5. Головне правило наукового дослідження

Перед запуском будь-якого тренування чи розрахунку:
1. Створіть файл `THEORY.md` у своїй експериментальній теці (зразок: [`c1/THEORY.md`](../Our%20try/03-deep-dives/D1-psi-to-scalars/c1/THEORY.md)).
2. Запишіть критерії: що саме ви очікуєте побачити і **що спростує вашу гіпотезу**.
3. Після запуску файл `THEORY.md` не редагується.
4. Оцінюйте невизначеність бутстрепом **за розрядами (shots)**, а не за окремими кадрами.
