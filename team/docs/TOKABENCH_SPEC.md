# Специфікація бенчмарку TokaBench-GS (Benchmark Specification v1.0)

**Версія:** 1.0  
**Дата:** 2026-10-09  
**Репозиторій:** Hackathon FMF / tokamld  

---

## 1. Завдання бенчмарку (Benchmark Tasks)

TokaBench-GS оцінює моделі машинного навчання для термоядерного синтезу за 4 взаємопов'язаними задачами:

1. **Реконструкція магнітного поля $\psi(R, Z)$ (Flux Map Reconstruction):**
   - Вхідні дані: струми в котушках полароїдного та тороїдального поля (`magnetics_*`), профілі Томсонівського розсіювання (`thomson_*`). Без прямих внутрішніх магнітних зондів.
   - Вихід: двовимірна карта магнітного потоку $\psi \in \mathbb{R}^{65 \times 65}$ на сітці DIII-D або MAST.

2. **Прогнозування інтегральних та геометро-топологічних скалярів ($\psi \to \text{Scalars}$):**
   - Два прямих скаляри: $q_{95}$ (safety factor на 95% потоку) та $\beta_N$ (нормалізований бета).
   - Сім функціоналів форми LCFS та рівноваги: $R_{\mathrm{axis}}, Z_{\mathrm{axis}}, \kappa, \delta_{\mathrm{top}}, \delta_{\mathrm{bot}}, V_{\mathrm{plasma}}, l_i$.
   - Обчислюються або безпосередньо з вихідного поля $\psi$ через стандартизовані оператори витягування LCFS, або через окремі голови моделі.

3. **Оцінка невизначеності поля (Simultaneous Conformal UQ):**
   - Побудова 2D конформних смуг $\hat{\psi}(R, Z) \pm c^* s(R, Z)$ з гарантією сумісного покриття на рівні $1 - \alpha$ (C6, P2.5).

4. **Фізична та топологічна спроможність (Grad-Shafranov & Topology Validity):**
   - Відносна нерівноважність Град-Шафранова $g(\psi)$;
   - Канонічність топології: $N_{\mathrm{spurious}} = |N_{\mathrm{O}} - 1| + N_{\mathrm{X}} = 0$ всередині сепаратриси.

## 2. Спліти даних та геш-контроль

- **Навчальний спліт (Train split):** Розряди `#000` – `#035` (36 розрядів, DIII-D).
- **Валідаційний спліт (Val split):** Розряди `#036` – `#047` (12 розрядів, DIII-D).
- **Калібрувальний спліт UQ (Cal split):** Розряди `#048` – `#059` (12 розрядів, DIII-D).
- **Контрольний тестовий спліт (Held-out Test split):** Розряди `#060` – `#067` (8 розрядів, 1521 кадр, DIII-D).
- **Хеш тестового спліту (Split SHA-256):** Фіксується за вмістом кешу `c2_cache` тестових розрядів для гарантії незмінності.

## 3. Метрики оцінювання

1. **Офіційна композитна метрика $S$:**
   $$S = 0.55 \cdot \max(0, R^2_\psi) + 0.15 \cdot \max(0, R^2_{qb}) + 0.10 \cdot (1 - \min(1, D_{\mathrm{LCFS}})) + 0.20 \cdot \mathrm{Consistency}$$
2. **Розширена фізична метрика $S'$ (Специфікація v2.1):**
   $$S'_s = S_s \cdot \mathcal{G}_{\mathrm{GS}}(\bar{g}_s) \cdot \mathcal{P}_{\mathrm{topo}, s}$$
   де:
   - $\mathcal{G}_{\mathrm{GS}} = 1.0$ при $\bar{g}_s \le 0.6328$, інакше $\exp(-(\bar{g}_s - 0.6328)/0.6328)$;
   - $\mathcal{P}_{\mathrm{topo}, s} = \frac{1}{T_s} \sum_t \exp(-0.5 \cdot N_{\mathrm{spurious}}^{(t)})$.
3. **Середня Град-Шафрановська нев'язка $g(\psi)$:** медіана по кадрах.
4. **Узгодженість $\mathrm{Consistency}$:** середній $R^2$ по 7 скалярах.
5. **Покриття конформних смуг:** спільне покриття (Joint Coverage) та середнє попіксельне покриття (Pixel Coverage) на рівні $\alpha = 0.90$.

## 4. Протокол довірчих інтервалів (CI Protocol)

- **Кластерний бутстреп за розрядами (Cluster bootstrap over shots):** $B = 1000$ вибірок із поверненням за тестовими розрядами.
- Для парних порівнянь моделей застосовується **ідентичний генератор псевдовипадкових чисел** (`seed=42`), щоб усунути вибіркову варіативність реплік.
- Статистична значущість різниці $\Delta M = M_A - M_B$: нуль не належить 95% довірчому інтервалу $[q_{0.025}, q_{0.975}]$.
