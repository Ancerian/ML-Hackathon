# TokaBench-GS: Кінематографічна доповідь (Cinematic HTML Film)

Цей модуль реалізує повнокадровий 16:9 кінематографічний виступ для захисту на Хакатоні ФМФ КПІ 2026.
Файл розроблено як чистий, автономний Canvas2D фільм (`index.html`), який працює на 100% офлайн за протоколом `file://` без жодних зовнішніх залежностей, CDN чи сторонніх шрифтів.

---

## Швидкий запуск

Відкрийте файл у будь-якому сучасному браузері:
```bash
open team/presentation/film/index.html
```
або через повний шлях у рядку адреси:
`file:///Users/ancerian/Documents/Projects/Hackathon_FMF/team/presentation/film/index.html`

## Режими роботи

1. **Режим доповідача (PRESENTER Mode — за замовчуванням):**
   - Керована хореографія: кожен біт чекає доповідача на ключовому кадрі (hold frame).
   - Плавний перехід між бітами при натисканні клавіш навігації.
2. **Кінорежим (FILM Mode):**
   - Безперервний автоплей повної таймлінії 12:00 (720 секунд).
   - Запуск через параметр URL: `index.html?mode=film`.
3. **5-хвилинна версія (Short Version):**
   - Концентрований таймлайн на 300 секунд (лише сцени S0, S3, S5, S7, S9).
   - Запуск через параметр URL: `index.html?short=1`.
4. **Режим захоплення кадрів (Headless Capture Mode):**
   - Детермінований покадровий рендеринг без анімаційного циклу:
   - Приклад: `index.html?capture=1&t=240` рендерить точний стан на 240-й секунді для скриншотів та QA.
5. **Режим налагодження (Debug Mode):**
   - Панель показників FPS, номера кадру та внутрішнього таймера: `index.html?debug=1`.

## Гарячі клавіші керування

| Клавіша | Дія |
| :--- | :--- |
| `ArrowRight` / `Space` | Наступний біт розповіді |
| `ArrowLeft` | Попередній біт розповіді |
| `Space` (у FILM) | Пауза / Відтворення |
| `N` | Відкрити окреме вікно нотаток доповідача (`Presenter Notes`) із синхронізованим 12-хвилинним таймером |
| `F` | Повноекранний режим (16:9 Letterbox) |
| `0` .. `9` | Миттєвий перехід до відповідної сцени (S0 – S9) |
| `[` / `]` | Перемотування на ±5 секунд |
| `Home` / `End` | Перехід на початок (0:00) або у фінал (12:00) |

## Вікно нотаток доповідача (`N`)

При натисканні клавіші `N` у новому спливаючому вікні відкривається суфлер доповідача:
- **12-хвилинний кольоровий таймер:**
  - Зелений (`#22c55e`): час до 10:00.
  - Жовтий (`#eab308`): 10:00 – 12:00 (попередження про ліміт регламенту).
  - Червоний пульсуючий (`#ef4444`): понад 12:00 (порушення регламенту).
- **Синхронізація в реальному часі:** Відображає поточний номер біта, короткий тезовий текст екрана (≤12 слів), детальну підказку (розмовний коментар) та анонс наступного біта.
- **Чистий головний екран:** На основному полотні фільму немає жодного інтерфейсного сміття під час доповіді.

## Структура сцен (10 сцен)

- **S0 (0:00–0:30):** Вступ: Парадокс $R^2$ ($R^2_\psi = 0.977$, питання «Це фізика?»).
- **S1 (0:30–1:15):** Токамак DIII-D (#203702, $j \times B = \nabla p$).
- **S2 (1:15–3:15):** Рівняння Ґреда–Шафранова (E6) та нев'язка $g(\psi)$.
- **S3 (3:15–5:15):** $R^2 \neq$ Фізика: порівняння істини ($g=0.0065$) та UNet ($g=0.8618$, поріг $g_{\text{ref}}=0.6328$).
- **S4 (5:15–6:30):** Шлюз Ґреда–Шафранова: реалізація Задачі 1 організаторів (шлюз $GS$).
- **S5 (6:30–8:00):** Моделі та довірчі інтервали: нерозрізненість за $S$ ($\Delta S = -0.0015$) та інверсія за $S'$-gate ($\Delta S' = -0.1129$).
- **S6 (8:00–8:45):** Тороїдальні силові лінії (гамільтонів трасувальник, $q=m/n$).
- **S7 (8:45–10:30):** Переріз Пуанкаре та хаос: моди 2/1 + 3/1, $A = 4.8\times 10^{-3}$, $S \approx 1.0\text{–}1.1$, FTLE $k=2.02$.
- **S8 (10:30–11:20):** Книга обліку: спростовані гіпотези R1–R13 та самоаудит T13.
- **S9 (11:20–12:00):** Висновки для дослідницької спільноти та атрибуція.
