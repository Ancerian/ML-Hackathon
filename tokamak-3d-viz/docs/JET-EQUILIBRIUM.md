## 2. Рівновага Солов'ева

### 2.1 Рівняння

Рівняння Ґреда—Шафранова для `B = ∇ψ×∇φ + F∇φ`:

```
Δ*ψ = R ∂/∂R (R⁻¹ ∂ψ/∂R) + ∂²ψ/∂Z² = −μ0 R² p′(ψ) − F F′(ψ)
```

У рівновазі Солов'ева p′ і FF′ сталі. Використано форму Cerfon & Freidberg,
*Phys. Plasmas* **17**, 032502 (2010), «One size fits all». Позначимо `R = R0 x`, `Z = R0 y`, `ψ = ψ0 u(x, y)`. Тоді

```
x ∂x(x⁻¹ ∂x u) + ∂y² u = (1 − A) x² + A
−μ0 p′ = C1 = (1 − A) ψ0 / R0⁴,     −F F′ = C2 = A ψ0 / R0²
u = x⁴/8 + A (½ x² ln x − x⁴/8) + Σ_{i=1..7} c_i u_i
```

Тут `u_i` — сім однорідних розв'язків (Δ*u_i = 0), парних по y (плазма симетрична вгору-вниз).
Їх точність перевірено в тесті `test_homogeneous_basis_is_exact`: символьне Δ* кожного дорівнює нулю.

Сім коефіцієнтів `c_i` визначаються сімома умовами Cerfon—Freidberg для D-межі:

- u = 0 у зовнішній і внутрішній екваторіальних точках та у верхній точці;
- ∂u/∂x = 0 у верхній точці;
- три умови кривини Міллера (N1, N2, N3).

Отже, **LCFS — це ψ = 0** з точністю до залишку підгонки.

Профілі при ψ_межі = 0:

```
p(ψ)  = −C1 ψ / μ0                   (≥ 0 усередині, бо A < 1)
F²(ψ) = F0² − 2 C2 ψ,   F0 = R0 B0   (вакуумне поле на межі)
```

### 2.2 Вибір двох вільних параметрів

При заданій формі та B0 залишаються два скаляри:

1. **A** задає поділ струму між тиском (R p′) і діамагнітним/парамагнітним внеском (FF′/R), тобто β_p.
   Від ψ0 β_p не залежить, бо і p, і B_pol² масштабуються як ψ0². A знайдено бісекцією з умови **β_p = 0,9** (p.83):
   **A = 0,09483**.
2. **ψ0** задає I_p лінійно. Його знайдено з умови **I_p = 3,8 МА**: **ψ0 = 15,637 Вб/рад**.

Означення, використані в коді (їх наведено тут, бо в літературі трапляються різні варіанти):

- `B_pa = μ0 I_p / L`, де L — полоїдальний периметр LCFS;
- `β_p = 2μ0⟨p⟩_V / B_pa²`;
- `l_i(1) = ⟨B_pol²⟩_V / B_pa²` (EFIT li);
- `l_i(3) = 2⟨B_pol²⟩_V V / (μ0² R0 I_p²)`.

I_p обчислено двома незалежними способами:

- за законом Ампера по межі, `∮B_pol·dl / μ0`;
- як інтеграл j_φ = (C1 R + C2/R)/μ0 по площі.

### 2.3 Адаптер до `Equilibrium`

`SolovevEquilibrium` — підклас `tokviz.equilibrium.Equilibrium`. Він будується з **сітки** ψ(R, Z)
193 × 257 (R 1,47…4,45 м, Z −2,40…2,40 м, крок 1,55 × 1,88 см), так само як кадри parquet.
Сплайн, контури, пошук осі, θ* і ψ_N успадковано без змін.

Відмінності від батьківського класу:

- `psi_bdy = 0` точно;
- `axis_sign = −1`: вісь є мінімумом ψ, як в EFIT для DIII-D;
- `q_at` і `B_phi` використовують **F(ψ)**, а не сталу F;
- скалярне `F` дорівнює вакуумному R0B0 для коду, якому потрібне одне число.

`FieldLinesFpsi` — це `FieldLines` з `B_φ = F(ψ)/R`.
Контурне q при A = 0,095 відрізняється від q зі сталою F менш ніж на 0,25 %, бо F(вісь)/F0 = 1,0025.

### 3.1 Порівняння q(a) із проєктом

- **D-плазма.** Табл. I.3-1 (p.83) дає 3,8 МА «for q(a) = 6» за формулою з виноски ††:
  `I_p q(a)/I_c ≈ k · ½(1 + (b/a)²)(a/R0)² / (1 − (a/R0)²)²`, де k = 1,1 взято з «particular computed peaked I_p configuration (β_POL = 0,9, q(a)/q(0) = 5,3)».
  Наша перевірка формули дає q(a) = 5,99.
  **Солов'ев дає q(a) = 5,81**, тобто на 3 % менше. Автори самі зазначають, що «навіть малі зміни форми перерізу можуть змінити k і відношення q до 30 %».
  Узгодження в межах 3 % — хороше.
- **Кругла плазма.** q(a) = 2,8 при 2,6 МА отримано наближенням великого аспектного відношення (виноска †: `I_p q(a)/I_c = (a/R0)²`).
  Циліндрична формула `q = 2π a² B0 / (μ0 R0 I_p)` дає 2,81, тобто це те саме число. Для D-плазми ця формула не застосовна.
  Для довідки, циліндричне q* з витягуванням дорівнює 3,68. Тороїдальний множник (1 − ε²)⁻² ≈ 1,48 піднімає його до ≈ 5,5…6.
- **q0 і q(a)/q(0).** Проєкт припускає піковий струм: q(a)/q(0) = 5,3…6, тобто q0 ≈ 1.
  **Солов'ев у принципі не може цього відтворити.** Його j_φ = (C1R + C2/R)/μ0 не залежить від ψ, струм плаский.
  Звідси q0 = 2,80, q(a)/q0 = 2,1 і низьке l_i ≈ 0,5.
  Для пікового профілю потрібен чисельний розв'язувач ГШ з p′(ψ), FF′(ψ), що спадають до межі. Це можливий наступний крок.
  Для візуалізації магнітної **топології** (вкладені поверхні, раціональні лінії) плаский профіль придатний.
  Але q = 1, 3/2 і 2 **усередині плазми немає**, тому демонстраційний острів 2/1 тут не резонансний.

### 3.2 Перевірки (тести)

- залишок межі 0,08 мм. Сіткова ψ_N = 1 відстоїть від D менше ніж на 1 см;
- I_p у межах 1 %: 3,8000 МА (закон Ампера) і 3,79996 МА (інтеграл по площі);
- B0 у межах 1 % трьома способами: F0, F(ψ) і Біо—Савар;
- q(ψ_N) строго монотонне, q0 з аналітичного еліпса біля осі;
- **q з трасування проти контурного q:** розбіжність ≤ 0,015 % при ψ_N = 0,1…0,95.
  q з трасування — це нахил розгорнутого геометричного кута від φ, 200 обертів. Поріг тесту 0,5 %;
- **ψ уздовж силових ліній зберігається:** дрейф 4×10⁻⁷ за 100 обертів (поріг 10⁻⁵);
- раціональні лінії замикаються: q = 3 після 3 обертів (зазор 0,44 мм), 7/2 після 7 (0,40 мм), 4 після 4 (0,04 мм), 5 після 5 (0,21 мм).

## 4. TF-рипл

### 4.1 Модель

- 32 D-подібні котушки (p.77).
- Центральна лінія обмотки: оцифрований контур отвору (`profiles/tf_coil_inner.csv`, Fig. IV.2-1, p.325), зсунутий назовні на 0,186 м.
  Це половина товщини ніг: 0,3735 і 0,371 м, p.325. Лінія проходить від R = 1,304 до R = 4,790 м.
- Базовий варіант — одна нитка на котушку. Для оцінки чутливості — 3 × 3 нитки на пакет 0,30 × 0,26 м.
- Струм Ic = 41 МА (basic), тобто 1,28 МА на котушку.
- Використано `rmp_coils.biot_savart`.
- B_max береться в площині котушки, B_min — посередині між котушками.
  Азимут котушки 0 читається з `kernel.tf_phi0_deg` (для 1975 це 0°). Саме відношення від азимута не залежить.

### 4.2 Два означення рипла — важливо

Підпис Fig. IV.2-4 (p.330): **«ε = 2 × (B_max − B_min)/(B_max + B_min)»**.
Отже, «3,6 %» у Табл. I.3-1 і значення в Табл. IV.2-4 (p.332) — це ε, а не сучасне δ = (B_max − B_min)/(B_max + B_min).
**δ = ε/2**, тобто проєктне значення δ ≈ 1,8 %.
Порівняння нижче зроблено в конвенції джерела. Наше δ також подано: у `physics.json` і на `ripple.png`.
Fig. IV.2-4 побудовано для 66,4 кА/виток (= 51 МА, extended). Відношення від струму не залежить.

### 4.4 Звідки залишкові розбіжності

1. **Оцифрована форма котушки.** Похибка оцифрування ±10…20 мм, README.
   Рипл біля краю зростає приблизно як e^{R/0,1 м}, тому зсув центральної лінії на ±2 см дає ε(4,21) = 4,18 / 3,22 %, тобто +14 / −12 %.
   Це основна невизначеність.
2. **Нитка чи скінченний переріз обмотки.** 3 × 3 нитки замість однієї збільшують ε на 2 %.
   Скінченна ширина пакета трохи згладжує поле між котушками.
3. **Внутрішня зона R < 4,1 м.** Тут наші значення на 20…35 % нижчі за оцифровану криву.
   Там ε < 2 %, і лінія рисунка товщиною ≈ 3 px, тобто ±0,1 %, сама становить 10…50 % значення.
   Крім того, у 1975 році розрахунок, імовірно, мав іншу модель провідника.
   Табл. IV.2-4 для тих самих країв плазми збігається з нами краще: у середньому 0,97.

Острів 2/1 тут не резонансний, бо q0 = 2,8 > 2. Скрипт повідомляє про це й пропускає його.
Приклад резонансного острова: 4/1 при ψ_N = 0,581, W = 0,085. Це ілюстрація, а не передбачення для JET.
