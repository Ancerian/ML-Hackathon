## Мета і задача
Отримати нові знання про утворення та еволюцію електронів-утікачів (ЕУ), про швидкий розрахунок імовірності парних зіткнень електронів з атомами й молекулами водневої плазми та про поглинання енергії повільної хвилі поблизу нижнього гібридного резонансу (НГР). Завдання: аналітично описати миттєвий стрибок густини ЕУ під час зриву й сплеску індукованого поля; створити швидкий і гладкий алгоритм для швидкісних коефіцієнтів; вивести рівняння повільної хвилі для E_z і розробити числові методи обходу сингулярності НГР.

## Модель і методи
- **Розд. 1:** швидкісний коефіцієнт ⟨σv⟩ для максвеллівського розподілу. Табличний переріз іонізації H (Janev et al.) апроксимується кусково-постійними елементами через функції Гевісайда, що дає аналітичну суму разом із 1-ю та 2-ю похідними за T. Далі застосовано ермітову інтерполяцію скінченними елементами 5-го порядку (коди FDM-P34, FEC-S1). Результат інтегрується в самоузгоджений код RFPP-St2 (Кранк–Ніколсон / Рунге–Кутта).
- **Розд. 2:** рівняння Максвелла в декартовій (слабко неоднорідній) геометрії з тензором проникності, діапазон ІЦ-частот. Виведено рівняння повільної хвилі для E_z та вектор Пойнтінга. Розв’язання: метод Гальоркіна зі СЕ 1-го порядку, LU-розклад; для сингулярності — метод штрафу (комплексний «патч» до F) і аналітичне продовження шляху інтегрування в комплексну площину. Приклад: D-плазма, B = 2,5 Тл, n = 10¹⁷ м⁻³, ω = 3·10⁸ с⁻¹, k∥ = 3 м⁻¹.
- **Розд. 3:** 0D-рівняння балансу густини ЕУ з первинною (Драйсер) і вторинною (лавинною) генерацією та втратами. Індуковане поле E∥(t) і T_e(t) задано кусково-лінійними функціями під час сплеску. Аналітичний розв’язок зводиться до інтегралів, які обчислюються квадратурами (код RAEGh-np, Fortran; перевірка у Wolfram Alpha). Установки: токамаки **T-10** та **EAST**; як мотивацію згадано JET, TEXTOR, DIII-D та ITER.

## Структура
- Розд. 1 — розрахунок швидкісних коефіцієнтів парних зіткнень електронів з атомами й молекулами (Гевісайд + ермітові СЕ).
- Розд. 2 — числове моделювання НГР: рівняння повільної хвилі, метод штрафу, аналітичне продовження, Гальоркін.
- Розд. 3 — феноменологічне моделювання генерації надтеплових електронів при нестійкостях зриву (T-10, EAST).

## Ключові рівняння
$$S_v=\langle\sigma v\rangle=\sum_{i=1}^{N-1}\frac{2v_{Te}\sigma_i}{\sqrt{\pi}}\Big[(1+u_{i-\frac12})e^{-u_{i-\frac12}}-(1+u_{i+\frac12})e^{-u_{i+\frac12}}\Big],\quad u=\frac{v^2}{v_{Te}^2}$$
Швидкісний коефіцієнт при кусково-постійному перерізі σ_i: v_Te — теплова швидкість, u_{i±1/2} — межі енергетичних інтервалів.

$$\frac{d}{dx}\!\left(\frac{k_0^2\varepsilon_\perp}{k_z^2-k_0^2\varepsilon_\perp}\frac{dE_z}{dx}\right)+k_0^2\varepsilon_\parallel E_z=\text{(джерела }\rho,\ j_z)$$
Рівняння повільної хвилі. НГР відповідає ε⊥ = 0, де коефіцієнт при старшій похідній обертається в нуль і виникає сингулярність. Безрозмірна тестова форма: (F E_z′)′ + G E_z = 0, F = n∥²ε⊥/(n∥² − ε⊥).

$$E_D=\frac{4\pi e^3 n_e L}{T_e},\qquad E_{CH}=\frac{4\pi e^3 n_e L}{m_e c^2}$$
Поле Драйсера та критичне поле Коннора–Гасті; L — кулонівський логарифм.

$$\frac{dn_r}{dt}=n_e\nu_e\lambda_e(\varepsilon)+\frac{n_r}{t_{av}(E_\parallel)}-\frac{n_r}{t_l},\qquad t_{av}\approx\frac{\sqrt{12}\,m_e c\,L\,(2+Z_{eff})}{9eE_\parallel}$$
Баланс густини ЕУ n_r: перший доданок — первинна генерація (λ_e залежить від ε = E/E_D і Z_eff), другий — лавина з характерним часом t_av, третій — втрати з часом t_l. У розрахунках втратами знехтувано.

## Основні результати
- Отримано аналітичні вирази для S_v та його похідних за T. Ермітова інтерполяція 5-го порядку прискорює розрахунок приблизно в 30 разів: 100 000 точок у діапазоні 0–1000 еВ обчислюються за 0,109 с проти 3,09 с. Функція та її 1-а й 2-а похідні залишаються неперервними.
- Код FEC-S1 попередньо табулює перерізи й прибирає багаторазове зчитування 24 файлів перерізів в основному коді RFPP-St2.
- Для повільної хвилі метод штрафу дає похибку поглиненої потужності до ~17 % з лінійним патчем і <5 % з параболічним.
- Аналітичне продовження (обхід НГР у комплексній площині) дає похибку ≲10⁻⁴ у широкому діапазоні ширини обходу x_w = 0,05–0,25. Косинусний обхід точніший за параболічний, бо має неперервну похідну.
- Для T-10 (n_e = 0,9·10¹⁹ м⁻³, Z_eff = 2, 2τ_br = 0,25 мс, E_m = 0,5–5 В/м) стрибок Δn_r зростає з E_m та тривалістю сплеску; на рис. 3.10 діапазон ≈10¹⁵–10¹⁹ м⁻³.
- Автор виявив неточність у попередньому моделюванні (Savrukhin et al., 2015): при E_m = 12,8 В/м і фактичному E_D ≈ 11–13 В/м умова E∥ ≪ E_D порушується, тому розрахунки для T-10 виконано з меншими полями.
- Для EAST (n_e = 2,2·10¹⁹ м⁻³, T_e = 550 еВ, Z_eff = 3, 2τ_br = 2,5 мс) модель спрощено, бо T_e під час сплеску майже стала. Автор повідомляє якісну узгодженість з експериментом і суперкомп’ютерними розрахунками.
- Практичний висновок: генерацію ЕУ можна послабити, зменшуючи амплітуду й тривалість сплесків E∥ через стабілізацію МГД-активності; ECRH згадано як приклад з літератури.

## Релевантність темі (0–5)
**2/5.** Робота стосується токамаків, але не потоку плазми як такого. Для проєкту «потік плазми в контурі токамака» корисні: (а) 0D-модель ЕУ як компонент сценарію зриву / струмового гасіння (зв’язок E∥, T_e, Z_eff), наприклад для JET-подібних розрядів; (б) методика швидких і гладких швидкісних коефіцієнтів (ермітові СЕ), яку можна перенести в рідинні / транспортні коди з атомними процесами (іонізація, рециклінг); (в) числові прийоми обходу резонансних сингулярностей (Гальоркін, аналітичне продовження) для хвильових модулів нагріву.

## Обмеження/зауваження
- Модель ЕУ 0D, без просторової структури, дифузії та релятивістських втрат. Вона застосовна лише при ε = E∥/E_D ≪ 1, що сам автор визнає як обмеження для зривів в ITER.
- Для EAST і T-10 порівняння з експериментом переважно якісне; кількісних розбіжностей не наведено.
- Задача НГР є 1D-тестовою (лінійний профіль ε⊥, граничні умови Діріхле), без реальної тороїдальної геометрії.
- Внутрішня непослідовність: у тексті розд. 3 згадано метод Гауса, у висновках до розділу — метод Сімпсона. Є також друкарські помилки в назвах розділів.
- Розрахунок S_v продемонстровано лише для іонізації атома H.
