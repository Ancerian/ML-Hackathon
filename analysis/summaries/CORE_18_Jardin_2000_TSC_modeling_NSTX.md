# S. C. Jardin, S. Kaye, J. Menard, C. Kessel, A. H. Glasser. Tokamak Simulation Code Modeling of NSTX. Princeton Plasma Physics Laboratory, Report PPPL-3472 (UC-70), липень 2000, 7 с. (PDF)

- **Файл:** CORE_18_Jardin_2000_TSC_modeling_NSTX.pdf
- **Тип:** звіт (коротка доповідь)
- **Тематичний кластер:** (5) інтегроване моделювання і коди; дотичний до (1)

**Мета і задача.** Показати результати порівняння (бенчмарку) коду TSC з першими даними сферичного тора NSTX, застосування TSC разом зі стабільнісними кодами для прогнозу балонної стійкості та моделювання експериментів з коаксіальною інжекцією спіральності (CHI).

**Модель і методи.** **TSC (Tokamak Simulation Code)** — еволюція вільнограничної аксіально-симетричної плазми на резистивному та енергетичному часових масштабах. Рівновага та рівняння поля — на 2D декартовій сітці; граничні умови плазма/вакуум/провідники — неперервність полоїдального потоку. Усереднені по магнітних поверхнях рівняння переносу тиску й густини — у потокових координатах, матрично-неявними методами; довільна транспортна модель (неокласичний опір, бутстреп, нагрів, струмогенерація, α-нагрів, випромінювання, пелети, пилкоподібні коливання, балонна модель). Колові рівняння котушок PF з індукованими струмами в пасивних структурах, зворотний зв'язок по струму/положенню/формі, halo-струми. Стійкість — пакет балонної стійкості TSC та **DCON**.

**Ключові рівняння.** (у звіті формул немає; нижче — стандартні рівняння, які розв'язує такий клас кодів, наведені для орієнтиру)
$$\Delta^*\psi\equiv R\frac{\partial}{\partial R}\!\left(\frac1R\frac{\partial\psi}{\partial R}\right)+\frac{\partial^2\psi}{\partial Z^2}=-\mu_0R\,j_\phi$$
— рівняння для полоїдального потоку (Ґред–Шафранов) на 2D-сітці.
$$L_k\frac{dI_k}{dt}+\sum_{j\ne k}M_{kj}\frac{dI_j}{dt}+R_kI_k=V_k$$
— колові рівняння для котушок і пасивних провідників.

**Основні результати.**
- Для розряду NSTX №100920 з реальними струмами котушок TSC добре відтворює струм плазми, струми в корпусі та сигнали флюкс-петель; $T_e(0)\approx900$ еВ, $\beta\approx1.4$ %, напруга обходу ~1.5 В; потрібен множник 1.5 до «стандартних» коефіцієнтів переносу при 10 % C ($Z_{eff}=2.7$), або множник 1.0 при $Z_{eff}=5$.
- Розряд 1 МА №101522 ($Z_{eff}=3.7$, $\langle n_e\rangle=2.5\times10^{19}$ м⁻³): профіль струму залишається злегка порожнистим; перед завершенням поблизу $q=1$ з'являється область балонної стійкості.
- Прогноз із NBI 2→5 МВт: енергетично $\beta>15$ %, але балонна нестійкість приблизно при $\beta\approx12$ % через малий шир біля $q=1$ і піковий тиск.
- Моделювання CHI (розряд №102080, 148 кА): струми узгоджуються з експериментом, магнітні поверхні сильно спотворені, але замкнених поверхонь TSC не прогнозує.

**Релевантність темі (0–5): 2.** Не про потоки плазми, а про інтегроване моделювання еволюції рівноваги, струмів і керування формою. Корисна як приклад архітектури «транспорт 1.5D + вільнограничина рівновага + котушки» для розділу про інструменти моделювання.

**Обмеження/зауваження.** Дуже короткий документ (оглядова доповідь), без рівнянь і кількісної статистики похибок; установка — NSTX (не JET). Назва файлу відповідає вмісту.
